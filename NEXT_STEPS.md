# Next Steps

## Planned Features

- **LLM Integration**: Use an LLM agent to intelligently modify the train script each iteration
- **Parallel Runs**: Support running multiple optimization attempts in parallel
- **Remote Execution**: Run train scripts on remote machines or containers
- **Custom Metrics**: Support extracting multiple metrics and composite scoring
- **Visualization**: Built-in metric plotting over time
- **Plugin System**: Allow third-party templates and metric extractors
- **Resume Support**: Resume interrupted optimization loops from last checkpoint
- **Hyperparameter Sweeps**: Integrate with hyperparameter search strategies
- **Notification Hooks**: Slack/email notifications on new best results
- **Export**: Export results to JSON, CSV, or database formats
